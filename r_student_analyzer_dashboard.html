1 · Conditional statements

      
Decisions the program makes about data.

      
    
        
  • get_grade() – an if / else if / else ladder turns an average into A+ … F.
    • 
        
  • get_status() – decides Fail, Pass or Distinction.
    • 
        
  • if (failed == 0) next – skips students with nothing to review.
    • 
        
  • is.na(g) check – chooses between "eligible" and "not eligible" messages.
    • 
      

    
2 · Loops

      
Repeating work over many rows and values.

      
    
        
  • for (i in 1:nrow(students)) – main loop that analyses every student.
    • 
        
  • for (m in marks) inside count_failed() – counts failing subjects.
    • 
        
  • for (s in subjects) – finds the topper in each subject.
    • 
        
  • while (k <= nrow(ranked) && …) – walks the ranked list until averages drop below 90.
    • 
        
  • repeat { … break } – adds grace marks one at a time until the pass mark is reached.
    • 
        
  • next and break – loop-control keywords.
    • 
      

    
3 · Functions

      
Reusable, named blocks with arguments and return values.

      
    
        
  • get_grade(avg, pass) – returns a grade string.
    • 
        
  • count_failed(marks, pass) – returns a number.
    • 
        
  • get_status(avg, failed) – combines two inputs into a decision.
    • 
        
  • grace_marks(mark, pass, max_grace) – default argument, early return(NA).
    • 
        
  • summarise_class(results) – returns a named list().
    •

Run the project in R

    
    
      
  1. Install R (and optionally RStudio) from cran.r-project.org.
    2. 
      
  2. Open the R Code tab and click Download student_analyzer.R (or copy the code into a new script in RStudio).
    3. 
      
  3. In RStudio press Source, or from a terminal run: Rscript student_analyzer.R
    4. 
      
  4. Change pass_mark at the top of the script and run again — compare with the dashboard using the same value.
    5. 
    

    
Note: this dashboard re-implements the exact same logic in JavaScript so it can run live in a browser. The R script is the actual project; the dashboard is its visual front end.
